Library Loan Manager
Track books, borrowers, and current loans. Suggested classes: Book and Library.
Store books and borrowers with unique IDs. A book may have several copies. Add books and search by title or
ID.
Lend a book only if a copy is available and the borrower has fewer than three active loans. Update both the
loan record and available copies.
Return a loan using a return-day number. Update available copies and calculate late days: zero if on time,
otherwise return day minus due day.
Given a current day number, list overdue active loans and group them by borrower. Show each borrower’s
overdue-book count and total late days.
